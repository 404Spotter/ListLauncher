# ListLauncher
Launch files, commands, and programs from a dashboard of saved "playlists". Easy way to launch right back into a project that involves multiple files and programs across your system.


# Commands
    Create New List:
        $ listlauncher new-list "list_name" 
    Add PDF or File to Launch with Default:
        $ listlauncher add "list_name" ~/Documents/notes.pdf
    Run Project or File with Program like VSCode:
        $ listlauncher add "list_name" "code ~/projectsmy-project"
    View Saved Lists
        $ listlauncher list
    View Executions Saved to List:
        $ listlauncher show "list-name"
    Launch List:
    $ listlauncher "list_name"
